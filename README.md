# Hardline World

[Play Hardline World](https://builtecho.github.io/hardline-world/)

A standalone construction-site practice prototype for desktop, touch and Meta Quest Browser. Begin in New York City as a superintendent, learn the controls, and follow your project from design to handover. Explore other roles offers additional perspectives and cities.

This repository contains only the compiled hosting files. Editable source is preserved separately on the private prototype branch. It is not part of the main Hardline app.

## Publishing

GitHub Pages publishes the root of the `gh-pages` branch. `.nojekyll` serves the prebuilt files directly. To update, publish another verified build to this branch and update `build.json`. Keep the character credits, license files and dependency licenses. No build server, accounts or backend are required.

## Browser records

Each player's progress, notes and captures stay in their own browser on this site's origin. Download captures before clearing browser storage. Saves from earlier preview domains do not automatically transfer here.

## Quest

Open the HTTPS play link in Meta Quest Browser and choose Enter VR. Physical Quest comfort, tracking, readability, performance, audio and capture still require headset acceptance.
